# Veera dashboard (DeepSeek Harness)

Use only the current task's recorded owner identity, root and capability file. Reuse the current live link or obtain the validated URL and record path via `dashboard-info`. Start a missing dashboard with `dashboard` from the owned task worktree; it opens the browser automatically. Keep the process handle, follow the host policy and preserve terminal shutdown. Never invent identity, scan other sessions, or treat opening the dashboard as permission to resume implementation. If the browser cannot open, provide the working address and continue eligible work.

Controller commands run with `VEERA_HOST=dsh`, `--session-id $env:DSH_SESSION_ID` and the recorded capability file.
